# Trang tài liệu OxideR-Query

Trang này dựng bằng [Docusaurus](https://docusaurus.io/).

Nội dung nằm ở `../docs`, không phải ở đây.
`docusaurus.config.ts` trỏ plugin docs sang thư mục đó (`path: '../docs'`), nên tài liệu chỉ có một bản: đọc được dạng Markdown trên GitHub, và được trang này render.
Sửa nội dung thì sửa trong `../docs`.

Thứ tự chương lấy từ `sidebar_position` trong front matter của từng file; sidebar là autogenerated nên thêm một chương chỉ cần thêm file.

## Cài đặt

```bash
npm install
```

## Chạy thử

```bash
npm start
```

Mở dev server và tự nạp lại khi `../docs` đổi.

## Build

```bash
npm run build
```

Sinh trang tĩnh vào `build/`.
Build bật `onBrokenLinks: 'throw'` và `onBrokenAnchors: 'throw'`, nên một liên kết hỏng làm build fail thay vì lọt ra bản phát hành.

Xem thử bản đã build:

```bash
npm run serve
```

## Deploy

Config đặt sẵn cho GitHub Pages tại `oxider-system.github.io/OxideR-Query/`.

```bash
GIT_USER=<tên GitHub của bạn> npm run deploy
```

Lệnh này build rồi push lên nhánh `gh-pages`.
